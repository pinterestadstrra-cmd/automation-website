Log in

Enter your GitHub Personal Access Token (classic, repo scope). Only the token of this site's owner (pinterestadstrra-cmd) can log in - someone else's token will not log in at all. The token stays saved in this browser, so you stay logged in after a refresh.

Create a token: GitHub → your profile → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic), check repo, Generate. If you think someone else has your token, delete it there and make a new one - the old one stops working at once.
